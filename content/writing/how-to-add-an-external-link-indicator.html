Introduction

Do you know how some sites have all their external links marked with a special symbol? Well, I wrote a simple CSS code that does so automatically for all links on your website!

Also, tip: I prefer to add target="_blank" rel="noopener noreferrer" HTML attributes to all my external link tags, so that they open in a new window, like this: Neocities.

HTML code:

<a href="https://neocities.org/" target="_blank" rel="noopener noreferrer">Neocities</a>

The code itself

You can use an image (preferably SVG) to add external link marker:

(show code snippet) 
/* This is a comment, you can delete all comments later if you prefer */
    
a { /* this a standard CSS link selector */
color: #0069d9; /* any color you want, just make sure it meets accessibility requirements */
/* everything selected with the :not selector will NOT have the external link CSS styles applied to it */
&:not([href*="sqvrltastic.art"]) /* replace with your own website domain name */
:not([href*="localhost:1313"]) /* this is for development only, so it works on the local server; replace 1313 with whatever port number you use, or delete it if you don't need it */
:not([href^="#"])
:not([href^="/"])
:not([href^="./"])
:not([href^="../"])
:not([href^="mailto:"]) 
:not(:has(> img))::after {
content: "";
display: inline-block;
inline-size: 0.8em;
block-size: 0.8em;
aspect-ratio: 1/1;
margin-inline-start: 0.1em;
background-color: currentColor;
-webkit-mask: url("/assets/images/icons/external-link.svg") no-repeat
center / contain;
mask: url("/assets/images/icons/external-link.svg") no-repeat center /
contain;
} /* Replace the image URL with your own image path and make sure you use an icon that isn't copyrighted */

Alternatively, if you don't want to use an image icon, you can just add a Unicode symbol or an emoji:

(show code snippet) 
a {
color: #0069d9;
&:not([href*="sqvrltastic.art"])
:not([href*="localhost:1313"])
:not([href^="#"])
:not([href^="/"])
:not([href^="./"])
:not([href^="../"])
:not([href^="mailto:"])
:not(:has(> img))::after {
content: "🔗";
display: inline-block;
margin-inline-start: 0.1em;
font-size: 0.8em;
}
